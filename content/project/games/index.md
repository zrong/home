## SAGI GAMES 时代 {{% tag "2017~2023" "dark" %}}

### 休闲游戏 {{% tag "2018~2020" "dark" %}}

- 2018年开始做休闲游戏，一年数十款精品游戏。
- 2018-03 《天才射手》
- 2018-07《碰碰大作战》
- 2018-11《街头大乱斗》3天 DAU 破百万。
- 2019-05 《抢夺大作战》《画线大逃亡》《最后的英雄》《单挑篮球》《漂移碰碰赛车》
- 2019-06 进入手Q小游戏，《碰碰大作战》获得手Q最具潜力游戏。
- 2019-07 进入百度小游戏，总注册人数破干万。
- 2019-08 进入头条小游戏，UGC内容观看次数超1000,000次。
- 2019-09 进入 OPPO 小游戏，日新增20万。
- 2019-09 代理发行多个小游戏。
- 2019-10 小游戏买量 DAU 过百万。
